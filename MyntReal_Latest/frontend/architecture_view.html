Stagewise Date Bucketing Intelligence

To eliminate lead discrepancies, post-won pipeline stages are bucketed dynamically using exact stage-update timestamps:

Pipeline Stage Primary Timestamp Used Fallback Hierarchy
Installed installation_date status_updated_at → submit_date
Balance Pending status_updated_at installation_date → submit_date
Subsidy Pending status_updated_at installation_date → submit_date
At Bank status_updated_at submit_date → created_at

Key Database ORM Schemas

  • CRMLead: Master lead table storing contact info, segment IDs, pipeline status, and timestamps.
  • StaffEmployee: Staff authentication, role codes, department IDs, and referral uplines.
  • SignupCategory: Multi-segment categories (Solar, EV B2B, EV B2C, Real Dreams, etc.).
  • ExpenseEntry: Financial ledger, JV party entries, TDS challan allocations.
  • TicketAttachment: Support attachments, photo proof, compressed media URLs.

1. Monolithic HTML Migration (Active Next.js 14 Upgrade)

In Progress

Next.js 14 App Router initialized to replace legacy HTML files with React Server Components, TypeScript types, and Tailwind CSS modules.

2. AWS Micro-Instance RAM Constraints

Infrastructure Constraint

The current AWS Elastic Beanstalk deployment runs on a 1GB RAM micro instance. Restricting Uvicorn to a single worker process prevents memory spikes above 100%.

3. Absence of In-Memory Caching (Redis)

Performance Bottleneck

Monthly/weekly trend aggregations query PostgreSQL directly on every dashboard load. Without a Redis caching layer, heavy executive queries hit the database repeatedly during peak usage.

4. Automated Test Suite Coverage

Quality Assurance Gap

High reliance on manual smoke testing rather than automated Cypress/Playwright end-to-end integration tests in continuous integration (CI) pipelines.
